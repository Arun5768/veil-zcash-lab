# Security scope

This is an unaudited educational prototype. Do not use it to protect or move funds. Never enter private keys, seeds or private viewing keys. Do not pay published test-vector addresses. Passing tests is not a security guarantee.

Report reproducible bugs to the project owner using the contact on their portfolio, without attaching secrets or private user data. No production incident-response SLA is offered. Maintain a minimal public test case for parser defects.

Public deployment is not yet approved. Any future deployment needs the provided CSP headers, HTTPS, dependency review and independent protocol review. The UI must preserve the distinction between encoding verification, hypothetical receiver policy and unimplemented settlement verification.
